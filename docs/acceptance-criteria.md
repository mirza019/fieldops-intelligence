# Acceptance criteria

## Functional

- KPI values and definitions are shared across analytics surfaces.
- Synthetic data remains fictional and public-safe.
- Streamlit app renders all primary pages without exceptions.
- API endpoints enforce role-based access and return structured data.
- AI analysis is grounded in validated KPI evidence and not arbitrary SQL.
- Power BI source structure exists and validates structurally.

## Quality

- Unit tests cover KPI diagnostics and simulation behavior.
- Core Python tests pass in the project environment.
- Known external dependencies, such as Windows Desktop validation, are clearly documented.

## Portfolio quality

- The project reads as a credible synthetic operational analytics portfolio rather than an employer-specific artifact.
- Documentation records status honestly and separates implemented features from external requirements.
